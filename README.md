# CODE DEATH

A real-time collaborative development workspace where developers can code, communicate, and work on projects together.

## Features

- 🔐 Firebase Authentication
- 👥 Create and Join Rooms
- 💻 VS Code-style Code Editor
- ⚡ Real-time Code Collaboration
- 📁 Project & File Management
- 🖥️ Integrated Terminal
- 🤖 Gemini AI Coding Assistant
- 🎥 Video & Audio Collaboration
- 🖥️ Screen Sharing
- 📦 Import & Export Projects
- 🔄 Undo, Redo, Find & Replace
- 📱 Fully Responsive UI

## Tech Stack

- React
- JavaScript / TypeScript
- Firebase
- Firestore
- WebRTC
- Gemini AI
- Monaco Editor
- Node.js

## How It Works

1. Create an account or log in.
2. Create a new room or join an existing room.
3. Open or import a project.
4. Edit code together in real time.
5. Run the project using the integrated terminal.
6. Use Gemini AI for coding assistance.
7. Communicate using video, audio, and screen sharing.

## Room Roles

### Host
The host can manage the room and its permissions.

### Member
Members can collaborate on the shared project according to the permissions provided by the room.

## Project Management

CODE DEATH supports:

- Creating files and folders
- Editing and saving files
- Copy, paste, cut
- Undo and redo
- Find and replace
- Importing projects
- Downloading projects as ZIP
- Running projects through the integrated terminal

## AI Assistant

The built-in Gemini AI assistant can help with:

- Explaining code
- Finding errors
- Fixing errors
- Generating code
- Refactoring
- Optimizing code
- Generating tests

## Collaboration

Multiple users can work inside the same room and edit the same project in real time.

Users can also communicate through:

- Video
- Microphone
- Screen sharing

## Security

CODE DEATH uses Firebase Authentication and security rules to protect rooms and project data.

Room permissions are enforced for both the application and backend.

## Responsive Design

CODE DEATH works across:

- Desktop
- Laptop
- Tablet
- Mobile

The interface adapts to different screen sizes for a better development experience.
